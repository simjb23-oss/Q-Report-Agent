# [2026 AX 공모전] 프로젝트 기획안 (신규 주제 확정본)

## 1. 프로젝트 개요
* **과제명:** 제조 중소기업을 위한 협력사 부품 시험성적서(COA) 멀티모달 자동 판독 및 공차·품질 판정 AI Agent
* **영문명:** **COA-Inspector (Check-Mate Agent):** Multimodal Inspection Certificate Parser & Automated Tolerance Evaluation Agent
* **부제:** 비정형 스캔/PDF 성적서의 실측치·공차 자동 추출부터 사내 검사기준 대조, 합/불 판정 및 공급사 반품통보서(NCR) 자동 발행까지
* **핵심 타깃:** 사출 성형품, 모터, 정밀 가공품 등 외주 부품을 입고받는 가전·기계·부품 제조기업의 수입검사(IQC) 및 품질보증(QA) 부서
* **슬로건:** *"수백 장의 종이 성적서와 엑셀 대조 노가다의 종말 — AI가 3초 만에 공차 이탈을 잡고 반품 통보서까지 완벽 작성"*

---

## 2. 추진 배경 및 제조 현장의 페인포인트 (Why)

### ① 협력사별 제각각인 비정형 성적서(PDF/종이) 수기 검토 한계
* 외주 부품(사출 케이스, 모터 코어, 샤프트, 패킹 실링재 등) 입고 시 협력사가 제출하는 시험성적서(COA, Mill Sheet, 검사성적서)는 표준 양식이 없음.
* 삐뚤깨뚤하게 스캔된 PDF, 팩스본, 서명/도장이 찍힌 종이 문서 등 포맷이 제각각이라 기존 룰 기반 OCR로는 인식이 불가능함.
* 검사원이 육안으로 수백 개의 치수(외경, 내경, 동심도, 조도, 경도 등)를 사내 도면/검사기준서 엑셀과 하나하나 대조하느라 심각한 병목 발생 (성적서 1건당 20~30분 소요).

### ② 수기 대조 오류로 인한 조립 라인 투입 및 대규모 불량 손실
* 사람이 수작업으로 검토하다 보니 미세 공차(예: 상한 +0.05mm 초과, 하한 -0.02mm 이탈)나 재질 스펙 누락을 놓치는 휴먼 에러(Human Error)가 빈번히 발생.
* 불량 부품이 수입검사를 통과하여 조립 라인에 투입될 경우, 완성품 조립 불량, 라인 셧다운, 완제품 신뢰성 시험 파손으로 이어져 수천만 원~수억 원의 직간접 손실 초래.

### ③ 부적합 발생 시 반품 및 시정조치 통보의 지연
* 불합격(NG) 판정 시 검사원은 협력사에 보낼 '부적합 보고서(NCR: Non-Conformance Report)'나 '반품 통보서'를 별도 워드/한글 양식으로 작성해야 함.
* 이 과정에서 로트번호, 이탈 항목, 도면 규격치, 실측치 등을 재작성하느라 최소 반나절~하루가 소요되어 협력사의 원인 분석 및 대체 로트 투입이 지연됨.

## 3. 핵심 솔루션 및 Multi-Agent 아키텍처 (What & How)

```
[입력 데이터]
협력사 성적서 (PDF / 이미지 / 스캔본)
       ▼
┌─────────────────────────────────────────────────────────────┐
│ [Agent-1] Multimodal COA Parser Agent                       │
│ - Vision-LLM(Gemini 1.5 Pro / GPT-4o) 기반 문서 레이아웃 분석│
│ - 비정형 표, 필기체, 도장 노이즈 속에서 검사항목/실측치/단위/로트번호 구조화 추출 │
└──────────────────────────────┬──────────────────────────────┘
                               │ JSON 추출 데이터
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ [Agent-2] QC Spec & Tolerance Checker Agent                 │
│ - 사내 검사기준 DB (품목별 도면 기준치, ±상하한 허용공차, 재질 규격) 대조 │
│ - 항목별 합격(PASS) / 불합격(NG) / 주의(Warning, 공차 80% 근접) 자동 판정 │
│ - 종합 판정: [최종 입고 승인] vs [전량 반품/부적합 판정]     │
└──────────────────────────────┬──────────────────────────────┘
                               │ 판정 결과 리포트
                               ▼
┌─────────────────────────────────────────────────────────────┐
│ [Agent-3] Quality Action & NCR Generator Agent              │
│ - PASS 시: ERP 연계용 수입검사 전계 데이터셋 자동 생성      │
│ - NG 시: 부적합 항목/치수 이탈량/도면 스펙 명시된           │
│   표준 '부적합 보고서(NCR) 및 협력사 반품 통보서' 즉시 자동 작성 │
└─────────────────────────────────────────────────────────────┘
                               │
                               ▼
[출력 및 액션]
- Streamlit 실시간 수입검사 관제 대시보드
- 원클릭 NCR PDF 다운로드 및 협력사 통보 메일 초안 완성
```

## 4. 3대 특화 AI Agent 세부 역할

| 에이전트 명칭 | 주요 역할 및 기술 메커니즘 | 입출력 데이터 |
| :--- | :--- | :--- |
| **Agent-1<br/>COA Parser** | • 비정형 성적서 이미지/PDF를 시각적으로 분석<br/>• 표 구조, 헤더(항목, 규격, 시편별 실측치 n=1~5), 단위(mm, kgf, HRC) 정밀 파싱<br/>• 회전·기울어짐, 음영, 도장에 강건한 멀티모달 프롬프트 엔지니어링 | **In:** 성적서 PDF/JPG<br/>**Out:** 정형 JSON (부품명, Lot, 치수 실측 배열) |
| **Agent-2<br/>QC Tolerance Checker** | • 추출된 부품코드 기반 사내 마스터 스펙(도면 공차 DB) 매핑<br/>• 수학적 공차 계산 ($LSL \le Value \le USL$ 검증)<br/>• 단순 수치뿐 아니라 원소재 재질(SUS304, ABS 등) 및 표면처리 스펙 일치성 판정 | **In:** JSON + 사내 Spec DB<br/>**Out:** 항목별 판정표 (PASS/NG/Warning, 편차값) |
| **Agent-3<br/>NCR & Action Generator** | • NG 발생 시 품질관리 실무 표준 서식(부적합품 통보서) 자동 생성<br/>• 불량 현상 기술문구("외경 상한공차 0.03mm 초과로 조립 간섭 우려") 전문적 작성<br/>• 협력사 귀책 사유 및 1차 조치(전량 반품 및 개선대책서 제출 요구) 통보서 발행 | **In:** 종합 판정 결과<br/>**Out:** 표준 NCR 보고서 (Markdown/PDF/메일문구) |

## 5. 도입 효과 및 정량적 목표 (Impact)

| 구분 | 기존 수작업 (As-Is) | AI Agent 도입 후 (To-Be) | 개선율 / 비고 |
| :--- | :--- | :--- | :--- |
| **성적서 검토 시간** | 건당 20 ~ 30분 | **건당 5초 이내** | **99% 시간 절감** |
| **공차 판정 오류율** | 검사원 피로도 따라 3~5% 휴먼에러 | **0% (수학적 룰 기반 완벽 검증)** | **불량품 라인 투입 원천 차단** |
| **부적합 보고서(NCR) 작성** | 양식 취합 및 작성에 1~2시간 소요 | **원클릭 자동 완성 (10초)** | **95% 이상 단축** |
| **검사 데이터 자산화** | 종이철 보관 또는 단순 스캔본 사장 | **전수 데이터베이스화 (ERP/MES 연계)** | **협력사별 불량률 트렌드 분석 가능** |

## 6. 개발 및 데모 시연 시나리오 (Streamlit)
1. **화면 분할 뷰(Split View):**
   * 좌측: 업로드된 협력사 성적서 원본 (PDF/이미지) 인터랙티브 뷰어
   * 우측 상단: AI가 실시간 파싱한 품목 정보(Part No, Lot No, 공급사) 및 도면 스펙 매칭 현황
2. **인터랙티브 판정 테이블:**
   * 검사항목별 `도면 기준치`, `허용공차(하한~상한)`, `협력사 실측치`, `편차(Delta)`, `판정(PASS/NG)`
   * NG 항목은 붉은색 배지 및 경고 툴팁 표기
3. **원클릭 업무 종결 액션:**
   * [입고 승인 버튼]: PASS 건 ERP 전계 데이터 JSON 미리보기
   * [반품 통보서 발행 버튼]: NG 건에 대해 협력사 발송용 '부적합 시정조치요구서' PDF 다운로드 및 이메일 전송 기능
