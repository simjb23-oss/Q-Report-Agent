## 1. 대회 핵심 분석 및 심사위원 공략 포인트

### 📌 대회의 본질과 심사 기준
* **주최/주관:** 경상남도, 창원특례시, 진주시 / (사)경남인공지능ICT협회, 경남TP, 경상국립대, 국립창원대 등
* **평가 핵심 공식:**
  $$\text{수상 가능성} = \text{현장 밀착형 실무 문제(Pain Point)} \times \text{AI Agent다운 워크플로우(도구·판단·액션)} \times \text{동작하는 MVP 시연}$$
* **심사위원 관점:**
  * 단순 LLM 챗봇("질문하면 답변하는 GPT")은 **탈락 1순위**입니다.
  * 심사위원단(지역 기업 임원, 교수, 테크노파크 전문위원)은 **"실제 경남 제조/산업 현장의 고질적인 비효율을 AI가 자율적으로 도구를 써서 해결하고 업무를 종결하는가?"**를 봅니다.
  * **일반부(가전/제조 재직자)의 절대적 무기:** 대학생 팀이 흉내 낼 수 없는 **"실무 용어(COA, 공차, NCR, 8D, VOC, 사출/공정 결함)"**와 **"현실적인 데이터 파이프라인"**을 제시하면 시작부터 가산점을 확보합니다.

## 3. 추천 프로젝트 주제 비교 및 최적의 선택

현재 기획된 2가지 유력 후보 중 **팀의 리소스와 발표 임팩트**에 맞춰 선택할 수 있습니다.

| 항목 | 후보 A. 부품 성적서(COA) 공차 판정 Agent (추천 ⭐⭐⭐) | 후보 B. 글로벌 VOC 기반 결함 감지 Agent (추천 ⭐⭐) |
| :--- | :--- | :--- |
| **프로젝트명** | **COA-Inspector (Check-Mate)** | **VOC-Sentinel (M-Guard)** |
| **타깃 업무** | 수입검사(IQC), 협력사 시험성적서 공차 대조 | 해외 이커머스 리뷰/AS 불만 분석 및 설계 개선 |
| **핵심 기술** | Vision-LLM (멀티모달 PDF/표 파싱) + 룰 기반 판정 + NCR 리포트 생성 | 다국어 번역/필터링 + 엔지니어링 키워드 분류 + R&D 설계변경서 생성 |
| **시연 임팩트** | **극상:** 복잡한 비정형 PDF를 넣자마자 빨간색 NG 배지가 뜨고 반품 통보서가 즉시 출력되는 시각적 효과 | **우수:** 대량 리뷰 데이터 워드클라우드/추이 차트 및 설계 권고서 출력 |
| **데이터 준비 난이도** | **쉬움:** 실제/가상의 시험성적서 PDF 5~10장만 있으면 완벽한 데모 구성 가능 | **보통:** 아마존/스마트스토어 리뷰 크롤링 또는 생성 데이터 필요 |
| **심사위원 반응** | "당장 우리 공장/협력사 관리에 도입하고 싶다"는 즉각적 반응 유도 | "마케팅-품질-설계를 잇는 참신한 시도"로 평가 |

> 💡 **최종 권장:** 8일이라는 짧은 개발 기간과 3분 시연 영상의 파괴력을 고려할 때, **[후보 A: COA 시험성적서 공차 판정 Agent]**가 시각적 데모 완성도와 실무 적용성 측면에서 가장 높은 점수를 받을 수 있습니다.

## 4. 8일 완성 MVP 개발 스택 및 아키텍처

대회 규정상 완벽한 상용화 앱이 아닌 **"실제 동작하는 Level 3(MVP)"**가 최고 목표입니다. 8일 안에 끝내는 최적의 테크 스택:

```
[사용자 화면 (Streamlit)]
  │ 1. PDF/이미지 업로드 & 검사 시작
  ▼
[FastAPI / Python 파이프라인]
  │
  ├─▶ 1단계 [Vision Parser]: Gemini 1.5 Pro / GPT-4o
  │      - 비정형 표/필기/도장 속 실측치 JSON 구조화
  │
  ├─▶ 2단계 [Spec Matcher & 판정기]: Python + Pandas
  │      - 사내 마스터 스펙 DB(엑셀/SQLite)와 비교
  │      - Upper/Lower Tolerance 수식 검증 (PASS / NG)
  │
  └─▶ 3단계 [Report Generator]: Jinja2 / ReportLab / Markdown
         - NG 발생 시 협력사 발송용 NCR(부적합보고서) PDF 자동 렌더링
```

* **Frontend/UI:** `Streamlit` (Python만으로 하루 만에 반응형 대시보드 구축 가능)
* **AI Engine:** `Gemini 1.5 Pro` 또는 `GPT-4o` (긴 컨텍스트와 표/이미지 인식 능력이 뛰어남)
* **프레임워크:** Python Native + `LangChain` (필요시)
* **저장소:** `SQLite` 또는 사내 기준 엑셀 파일 (`spec_master.xlsx`)

## 5. 필수 제출물 5종 작성 전략

1. **참가 신청서 (과제소개 1P):**
   * 문제 정의(As-Is)를 수치화할 것 (예: 성적서 1장당 20분 소요, 연간 휴먼에러 3% 발생).
   * 솔루션(To-Be)의 파이프라인 흐름도를 텍스트/표로 깔끔히 도식화.
2. **개발완료보고서 (5P 이내):**
   * 분량 낭비 없이 `배경/타깃(1P)` ➔ `에이전트 아키텍처(1.5P)` ➔ `핵심 기능 및 구현(1.5P)` ➔ `성과 및 기대효과(1P)`로 구성.
3. **AI Agent 기술설명서 (1P):**
   * 공고문 요구사항인 **Goal / Workflow / AI / Tool·API / Memory·Feedback / 신규개발분** 6개 항목을 1장짜리 표로 일목요연하게 작성.
4. **시연 동영상 (3분 이내):**
   * 인트로/설명은 30초 컷! 나머지 2분 30초는 **실제 화면에서 파일 업로드 ➔ 판정 ➔ 리포트 다운로드** 과정을 직접 시연.
5. **발표자료 (10P 이내):**
   * 글씨를 줄이고 아키텍처 다이어그램, As-Is vs To-Be 비교표, UI 캡처 위주로 구성.
