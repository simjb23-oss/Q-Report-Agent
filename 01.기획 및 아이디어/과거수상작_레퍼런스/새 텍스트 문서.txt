추천 1. [제조/품질] "신입도 베테랑처럼 대응하는 공정 불량 원인 분석 & 시정조치 자동화 에이전트"
⭐ 가장 추천 (임팩트 최상 / 구현 난이도 보통)

문제 상황: 제조 현장이나 협력사에서 불량(모터 발열, 파손, 누유 등)이 터지면, 원인을 찾기 위해 수년 치 엑셀/PDF 문서를 뒤지느라 반나절이 날아가고 신입 사원은 손도 못 댐.

에이전트 동작 (웹 화면 시연):

작업자가 화면에 불량 증상 입력: "BLDC 모터 작동 중 비정상 발열 및 소음 발생"

에이전트가 가상의 과거 불량 이력 엑셀/규격서를 RAG로 3초 만에 검색.

산출물: 과거 동일 사례 기반 예상 원인 3가지(베어링 마모, 편심 등) + 표준 정비 체크리스트 + '시정조치 요구서(CAR)' 공문 초안을 화면에 즉시 생성 및 다운로드.

심사위원에게 먹히는 포인트: "경남 기계/제조 현장의 숙련공 부족 문제를 데이터와 AI로 즉각 해결하는 실용적 에이전트"라는 명분이 완벽함.

추천 2. [업무혁신] "수출·외주 협력사 다국어 검사 성적서 자동 검증 & 규격 판정 에이전트"
⭐ 구현 난이도 최하 (가장 쉬움 / 임팩트 상)

문제 상황: 해외(중국, 베트남 등)나 외주 공장에서 들어오는 부품 검사 성적서(Inspection Report)는 양식도 제각각이고 언어도 달라 일일이 수치와 허용 공차를 사람이 대조하느라 시간 낭비와 오류 발생.

에이전트 동작 (웹 화면 시연):

웹 화면에 해외 공장에서 받은 성적서(PDF 또는 이미지/표)를 드래그 앤 드롭으로 업로드.

에이전트가 사내 표준 규격 기준표와 자동 대조.

산출물: "외경 공차 ±0.05mm 초과 불량(NG) 2건 발견", "중국어/영어 비고란 한국어 자동 번역", "외주사에 보낼 재검사 요청 이메일 초안 자동 작성".

심사위원에게 먹히는 포인트: OCR/비전과 LLM 텍스트 요약을 결합해 번거로운 반복 수작업을 100% 자동화하는 모습이 눈에 바로 보임.

추천 3. [공공/지역/안전] "중소 제조현장 중대재해 예방을 위한 일일 위험성평가 & 안전수칙 자동 생성기"
⭐ 정책·공공 가점 확보용 (난이도 하 / 시의성 최상)

문제 상황: 중대재해처벌법 등으로 소규모 공장도 매일 '위험성평가표'와 '작업 전 안전점검표'를 써야 하지만, 전담 안전관리자가 없어 인터넷에서 베끼거나 형식적으로 때우는 실정.

에이전트 동작 (웹 화면 시연):

관리자가 오늘 작업 내용 2줄 입력: "5톤 호이스트 크레인으로 금형 교체 및 사출기 점검 작업"

에이전트가 산업안전보건공단 가이드라인 기반으로 위험 요인 분석.

산출물: 오늘 작업 맞춤형 위험성평가표(표 형태) + 아침 TBM(작업 전 10분 안전미팅) 대본 + 안전 체크리스트 자동 출력.

심사위원에게 먹히는 포인트: 지자체(경남) 주관 대회 특성상 공공성·사회적 안전 문제를 다루면 심사위원단(공공기관, 지자체 관계자)의 호감도가 매우 높음.
