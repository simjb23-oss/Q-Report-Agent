## 1. 🎯 한눈에 찾는 "어느 글자 바꿀 때 어느 파일?"

화면이나 보고서에서 바꾸고 싶은 글자의 종류에 따라 아래 표를 보고 해당 파일만 열어서 수정하시면 됩니다.

| 바꾸고 싶은 글자/영역 | 수정할 파일 경로 | 파일 설명 |
| :--- | :--- | :--- |
| **대시보드 웹 화면 전체 글자**<br>(제목, 사이드바 문구, 버튼 이름, 카드 라벨 등) | `03.개발 및 데이터/src/app/main.py` | 웹 화면(UI)의 모든 텍스트가 들어있는 메인 파일 |
| **사이드바 및 UI 영구 고정 규격**<br>(4대 고정 블록, 네비게이션, 인프라 모니터 등) | `04.발표 및 최종 제출/사이드바_및_UI_고정_설계_규격서.md` | 사용자 확정 영구 픽스 UI 규격서 |
| **AI 이메일 초안 문구**<br>(한국어/중국어/영어 메일 인사말, 본문, 서명 등) | `03.개발 및 데이터/src/core/email_drafter.py` | 이메일 템플릿과 프롬프트가 작성된 파일 |
| **공식 부적합 보고서(NCR) 서식**<br>(NCR 제목, 발신팀명, 협력사 요구사항 문구 등) | `03.개발 및 데이터/src/core/ncr_generator.py` | HTML 및 마크다운 NCR 양식을 생성하는 파일 |
| **사내 제품 스펙 & 도면 공차 수치**<br>(기준치, 상한/하한선, 부품명, 단위 등) | `03.개발 및 데이터/data/internal_part_spec_master.json`<br>`03.개발 및 데이터/src/core/qc_master_db.py` | 우리 회사 도면 기준치와 공차가 적힌 마스터 DB |
| **협력업체 정보**<br>(업체명, 담당자 이름, 연락처 이메일, 주소 등) | `03.개발 및 데이터/data/vendors.json`<br>`03.개발 및 데이터/src/core/vendor_manager.py` | 협력사 리스트와 프로필이 저장된 파일 |
| **구글 스프레드시트 주소 / 웹훅 URL** | `03.개발 및 데이터/data/sheet_config.json` | 구글 시트 연동 웹훅과 문서 URL 설정 파일 |
| **제출용 보고서 & 발표 대본 글자**<br>(PPT 기획서, 기술설명서, 3분 시연 대본 등) | `02.제출서류 및 신청/` 폴더 내 `.md` 파일들<br>`04.발표 및최종 제출/` 폴더 내 `.md` 파일들 | 심사위원 제출용 한글/마크다운 서류들 |

## 2. 📂 핵심 수정 대상 파일 상세 안내

### ① `src/app/main.py` (웹 화면에 보이는 거의 모든 글자)
* **어떤 글자가 있나요?:**
  - 사이드바 타이틀: `[칼퇴보증] 품질 성적서 에이전트`
  - 섹션 제목: `[1] 완제품 출하검사 성적서 입력`, `[4] 시험항목별 정밀 공차 판정표`, `[Agent 자율 액션]`
  - 버튼 이름: `AI 출하검사 성적서 자동 감사 시작`, `품질팀장 전자서명 & 최종 결재 승인`, `AI 이메일 초안 생성/갱신`
  - ROI 통계 숫자 및 단위: `25분 ➔ 1.2초`, `1.8억원/년` 등
* **수정 방법:**
  - 파일을 열고 `Ctrl + F`를 눌러 바꾸고 싶은 단어를 검색한 뒤, **따옴표(`" "` 또는 `' '`) 안에 있는 글자만** 수정하시면 됩니다.
