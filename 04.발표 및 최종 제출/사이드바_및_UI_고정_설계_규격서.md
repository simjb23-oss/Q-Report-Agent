# 📌 [사이드바 및 UI 고정 설계 규격서 (Permanent UI Layout Spec)]
> **본 문서는 사용자 요청에 의해 영구 픽스(Fix)된 대시보드 사이드바 및 화면 레이아웃 규칙입니다.**  
> 향후 어떤 수정이나 유지보수 작업이 있더라도 아래 명시된 **사이드바 구성 4대 블록** 및 **하단 클라우드 시트 뷰어**는 **절대 임의로 삭제되거나 변경되어서는 안 됩니다.**

## 2. 📋 4대 블록별 상세 구현 명세

### 블록 1: [브랜드/팀] 헤더 카드
* **브랜드/팀명:** `⚡ Q-Report Agent | 팀 칼퇴보증`
* **시스템 상태 인디케이터:** 
  * 분석 전: `● Status: IDLE (System Ready)` (초록색 펄스 배지)
  * 분석 완료 후: `● Status: AUDIT_COMPLETE (Analysis Done)`
* **서브 카피:** 글로벌 OEM·ODM 완제품 출하검사 자율 감사 에이전트

### 블록 2: 📌 [메뉴 네비게이션] (Section Quick Jump)
사용자가 사이드바에서 클릭하여 원하는 화면 영역으로 즉시 이동하고, 메뉴별 단독 뷰 또는 전체 뷰를 제어:
1. `🔘 1. 성적서 자율 판독` ➔ 상단 `[1] 출하 성적서 입력`, `[2] 원본 대조`, `[3] 판정표`, `[4] Cpk 차트`, `[5] 위험도 및 NCR` 영역
2. `⚪ 2. 협력사 품질 분석` ➔ `[8] 협력사별 누적 성적서 이력 관리` (HOTOEM, MYLUX, 크리스탈 3사 필터)
3. `⚪ 3. 과거 이력 & 잠재 위험 분석` ➔ 누적 판정 상세 내역 테이블 및 AX ROI 성과 카드
4. `⚪ 4. 전사 동기화 (Google Sheet)` ➔ `[9] 클라우드 실시간 품질 관제 (Google Spreadsheet 연동)`

### 블록 3: ⚙️ [에이전트 컨트롤 패널] (Inspection Controls)
1. **AQL 검사 엄격도:** 드롭다운 셀렉트박스
   * 옵션: `일반검사 Level II (기본)`, `강화검사 Level III (엄격)`, `수월한검사 Level I (완화)`
2. **AI 추론 엔진:** 라디오 버튼
   * 옵션 1: `Gemini 3.8 Flash (Multi-modal)`
   * 옵션 2: `로컬 룰베이스 Fallback 강제 (시연용)`

### 블록 4: 📡 [인프라 연동 상태 모니터] (Live Infrastructure Telemetry)
* **RapidOCR Engine:** `🟢 Active (초당 45매 고속 판독)`
* **Cloud Webhook:** `🟢 Synced (Apps Script 연동 완료)`
* **Memory Cache:** `🟢 24 Cases Loaded (성적서 DB 마운트)`

## 3. 🛡️ 개발자 안전 수칙 (Never Delete Checklist)

1. ❌ **사이드바를 임의로 단순화하거나 비우지 말 것:**
   - 사용자가 지정한 4개 블록(브랜드 헤더, 메뉴 네비게이션, 컨트롤 패널, 인프라 모니터)을 항상 유지한다.
2. ❌ **구글 스프레드시트 뷰어를 화면에서 삭제하지 말 것:**
   - 메인 화면 하단 `[9] 클라우드 실시간 품질 관제` 섹션의 CSV 파싱 실시간 표 및 바로가기 버튼은 100% 영구 보존한다.
3. ❌ **협력사 3사 예시(HOTOEM, MYLUX, 크리스탈)를 누락하지 말 것:**
   - 1단계 협력사 필터 및 8단계 누적 성적서 드롭다운에 상시 노출 상태를 유지한다.
