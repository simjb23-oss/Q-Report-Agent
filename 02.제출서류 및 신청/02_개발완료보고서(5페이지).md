### [Page 1] 1. 문제 정의 및 개발 배경 (Problem & Context)

#### 1-1. 경남 제조업 현장의 실제 문제 (Pain Point)
- 경남 창원/김해 등 주력 가전 및 기계 수출 제조업체(예: 휴롬 등)는 국내외 다수의 1·2차 OEM/ODM 협력사로부터 매월 수백 건의 **완제품 출하검사 성적서(Final Inspection Report / Certificate of Analysis)**를 수신합니다.
- 그러나 협력사마다 **성적서 양식이 제각각(비정형 PDF, 스캔본, 도장 날인)**이고, 사용 언어도 **한국어, 영어, 중국어(한자)**로 혼재되어 있습니다.
- 현재 품질보증팀(IQC) 담당자는 도면집을 일일이 찾아보며 **한 건당 평균 25분 이상 수기 대조**를 수행하고 있어, 월 100시간 이상의 단순 반복 행정 낭비가 발생합니다.
- 특히 미세 치수 오차(예: ±0.3mm)나 단방향 허용공차(예: 인장강도 60N 이상)를 육안으로 대조하다가 **도면 공차 오판정(Human Error)**이 발생할 경우, 부적합 로트가 생산 라인에 투입되어 수억 원대의 조립 중단 및 클레임 비용이 발생합니다.

#### 1-2. 프로젝트 목표 및 핵심 접근 방식
- **핵심 목표:** 비정형·다국어 성적서를 AI Agent가 1.2초 내 스스로 읽고, 사내 도면 한계공차(LSL/USL)를 전수 대조하여 **합격 시 [입고 승인서], 불합격 시 [표준 부적합 통보서(NCR/8D)]를 4대 포맷으로 자율 발행**하는 Level 3 MVP 완성.
- **Agent적 접근:** 단순 텍스트 챗봇이 아니라, **"목표 수립 ➔ 다국어 파싱 ➔ 도면 DB 공차 추론 ➔ 행정 문서 자율 빌드 ➔ 협력사 품질등급 실시간 갱신"**의 완결된 End-to-End 업무 흐름을 스스로 완주합니다.

### [Page 2] 2. AI Agent 구조 및 시스템 아키텍처 (Agent Architecture)

#### 2-1. Agent 6대 핵심 구성요소 설계
본 시스템은 경진대회 인정 기준인 **Agent 6요소(Goal, Plan, Reason, Tool, Memory, Feedback)**를 100% 만족하도록 설계되었습니다:

1. **🎯 Goal (목표 정의):** 출하검사 성적서 1건의 도면 규격 무결성 100% 전수 감사 및 공식 행정 조치 완결.
2. **📋 Planning (작업 계획 분해):**
   - `Step 1`: 다국어(KO/EN/ZH) 텍스트/표 스트림 파싱 및 품질 메타데이터 추출.
   - `Step 2`: 제품 모델코드 식별 및 사내 마스터 DB에서 LSL/USL 공차 한계선 자동 매핑.
   - `Step 3`: 각 시험항목별 실측치 편차(Delta) 정밀 추론 및 ISO 2859-1 AQL 결함 판정.
   - `Step 4`: 판정 결과에 따른 입고 승인서 또는 부적합 통보서(8D Form) 자율 빌드.
3. **🧠 Reasoning (공차 추론 엔진):** 
   - 양방향 공차: `(LSL + USL) / 2` 기준 편차 및 ±한계선 이탈 검출.
   - 단방향 공차: 하한/상한 단독 기준(예: 전원코드 인장강도 60N 이상)에 대해 기준치 대비 실측치 차이를 정확하게 계산하여 왜곡(Delta 0 현상) 원천 방지.
4. **🛠️ Tool Use (외부 도구 연동):**
   - `Tool_OCR_Parser`: PyMuPDF 및 Google Vision LLM API 연동.
   - `Tool_QC_Master_DB`: 5대 가전 품목 사내 도면 치수 및 전기안전 규격 DB.
   - `Tool_Vendor_Manager`: 협력사 품질 등급(A/B/C) 및 합격률 이력 관리 DB.
   - `Tool_Doc_Generator`: Excel(.xlsx), PDF(.pdf), HTML(.html), Markdown(.md) 4대 포맷 자동 빌더.
5. **💾 Memory / State (상태 기억):**
   - `st.session_state`를 통한 판정 세션 보존.
   - `audit_history`에 전수 검사 로그 영구 아카이빙.
   - `vendors.json`에 협력사 누적 검사 건수 및 합격률 실시간 동기화.
6. **🔄 Feedback & Self-Correction (자기 보정 루프):**
   - 공차 초과 검출 즉시 ERP 출하 보류(Lock) 발동 및 협력사 앞 8D 대책서 요구 워크플로우로 자동 전이.
   - 외부 네트워크 단절 시 오프라인 로컬 룰베이스로 100% 무중단 자동 폴백.

### [Page 3] 3. 핵심 기능 구현 및 기술 차별점 (Implementation)

#### 3-1. 하이브리드 지능형 파싱 & 3단 폴백 파이프라인
- **다국어(한/영/중) 자동 분류:** 중국 저장성 협력사(余姚市菲尔浦)의 한자 성적서부터 영문/국문 성적서까지 언어 태그를 자동 식별하여 적합한 파싱 규칙 적용.
- **3단 무중단 폴백 구조:** `PyMuPDF 벡터 파싱` ➔ `pypdf 텍스트 추출` ➔ `로컬 정규식 룰베이스 엔진`으로 연쇄 폴백되어, 인터넷이 차단된 사내 폐쇄망에서도 100% 무중단 가동 보장.

#### 3-2. 한글 CJK 벡터 폰트 임베딩 4-포맷 자율 리포팅
- 합격 시 `[출하검사 합격 인증 및 입고 승인서]`, 불합격 시 `[품질 부적합 통보서 (NCR/8D)]`를 자동 생성.
- PyMuPDF CJK 한국어 벡터 글꼴 임베딩을 통해 PDF 파일 내 한글 깨짐(`□□□□`) 현상을 완벽 해결하고, **Excel, PDF, HTML, Markdown 4가지 파일로 즉시 다운로드** 제공.

#### 3-3. 🏭 협력업체 마스터 관제소 (Vendor Management Master)
- **신규 협력사 등록 (Onboarding):** 상호, 국가, 품목, 적용규격, 담당자 등록 즉시 영구 DB 저장.
- **기존 협력사 관리:** 품질 등급(A/B/C) 및 상태(정상/중점관리/거래보류) 실시간 변경.
- **성적서 연동 품질 이력:** 검사 수행 시마다 해당 협력사의 검사 건수 및 합격률 자동 갱신.
