## 3. 원클릭 실행 방법 (심사위원 재현용)

### 방법 1 : 윈도우 배치파일 원클릭 실행 (가장 추천)
* **`03.개발 및 데이터`** 폴더 내의 **`COA_프로그램_실행.bat`** (또는 **`칼퇴보증_프로그램_실행.lnk`**) 파일을 더블클릭합니다.
* 파이썬 환경이 감지되면 필요한 패키지(`streamlit`, `pandas`, `plotly`, `pymupdf` 등)가 **자동 점검 및 1회 자동 설치**됩니다.
* 검은색 콘솔 창이 엔진으로 가동되며, 기본 웹 브라우저(`http://localhost:8501`)가 자동으로 열려 관제 대시보드가 구동됩니다.
* *(주의: 프로그램 구동 중 검은색 콘솔 창을 닫지 마시고 최소화해 두세요)*

### 방법 2 : CLI 터미널 직접 실행
```bash
# 1. 개발 폴더로 이동
cd "03.개발 및 데이터"

# 2. 의존성 패키지 설치
pip install -r requirements.txt

# 3. 애플리케이션 실행
python run.py
```
